# Tang Ping Sales Admin — Dashboard

Static dashboard for Tang Ping Live Cafe Bar (Zeoniq POS, outlet 03512).

- Single page: `index.html` (data embedded, phone numbers masked).
- A username/password gate is shown before the dashboard.
  **Caveat:** the data is embedded in the page, so the login is a convenience
  barrier, not real security. Anyone technical could bypass it and read the
  embedded numbers. For real protection use Vercel's password protection or a
  server-side data source.
- To change credentials: edit `AUTH_USER` / `AUTH_PASS` in `index.html`.
- No build step. Vercel serves `index.html` at the root.

Regenerated by `build_dashboard.py` (masked = `tang-ping-dashboard-cloud.html`).
